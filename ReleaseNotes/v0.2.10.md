# codex-opero v0.2.10

## 한국어

메뉴 하단의 버전을 클릭해 업데이트를 바로 확인하고, 앱에서 새 버전을 내려받아 설치할 수 있습니다.

### 변경 사항

- **수동 업데이트 확인**: 버전 표시를 클릭하면 하루 1회 자동 확인과 별개로 GitHub에서 최신 버전을 즉시 확인합니다. 최신 버전이면 안내창을 표시하고, 확인에 실패하면 원인을 안내합니다. 새 버전 표시(`v0.2.9 → v0.2.10` 등)를 클릭해도 브라우저 대신 같은 흐름으로 진행합니다.
- **릴리즈 노트 표시**: 새 버전이 있으면 시스템 언어에 맞는 릴리즈 노트를 업데이트 여부와 함께 표시합니다.
- **데스크탑 다운로드와 검증**: `업데이트`를 선택하면 진행률과 취소 버튼을 표시하며 릴리즈의 DMG를 데스크탑에 `codex-opero-<버전>.dmg`로 저장합니다. 크기와 SHA-256이 GitHub 릴리즈 정보와 일치하지 않으면 파일을 저장하지 않으며, 같은 파일이 이미 있으면 다시 받지 않습니다.
- **설치 후 재시작**: DMG를 화면에 열지 않고 새 앱을 꺼내 번들 식별자, 버전, 코드 서명을 확인합니다. 앱이 종료된 뒤 기존 앱을 교체하고 다시 실행합니다. 교체에 실패하면 기존 앱으로 되돌리고, 다음 실행 시 실패 원인과 함께 DMG로 직접 설치하도록 안내합니다.
- **설치 위치 확인**: 현재 앱 위치에 쓸 수 없으면 자동 교체 대신 받은 DMG를 엽니다.

### 검증

- 새 테스트 6개를 포함한 전체 91개 테스트가 통과했으며 v0.2.10(build 28) DMG 생성, 서명·체크섬 검증을 완료했습니다.
- 설치 스크립트의 정상 교체·재실행과 복사 실패 시 기존 앱 복구를 실제 실행으로 검증했습니다.
- 실제 v0.2.9 릴리즈 DMG로 다운로드, SHA-256 검증, 동일 파일 재사용, 잘못된 체크섬 거부, 취소, DMG 마운트·복사·검증·해제를 확인했습니다.
- 메뉴 UI의 안내창과 실제 설치 앱의 교체·재시작은 다음 릴리즈로 업데이트할 때 확인이 필요합니다.

v0.2.9 이하에는 이 기능이 없으므로 이번 버전은 DMG로 직접 설치해야 합니다. 처음 데스크탑에 저장할 때 macOS가 데스크탑 폴더 접근 허용을 요청할 수 있으며, 앱이 ad-hoc 서명이라 새 버전에서 다시 요청할 수 있습니다.

## English

Click the version in the menu footer to check for updates immediately, then download and install the new version from within the app.

### Changes

- **Manual update check**: Clicking the version checks GitHub for the latest release immediately, independent of the daily automatic check. Show a confirmation when already up to date, and explain the cause when the check fails. Clicking the new-version label (for example `v0.2.9 → v0.2.10`) follows the same flow instead of opening the browser.
- **Show release notes**: When a newer version is available, show its release notes in the system language alongside the update prompt.
- **Download to the Desktop with verification**: Choosing `Update` downloads the release DMG to the Desktop as `codex-opero-<version>.dmg`, with progress and a cancel button. Discard the file if its size or SHA-256 does not match the GitHub release, and skip downloading again when an identical file already exists.
- **Install and relaunch**: Extract the new app without opening the DMG in Finder and validate its bundle identifier, version, and code signature. Replace the existing app after it quits, then relaunch. If replacement fails, restore the previous app and explain the cause on next launch with instructions to install from the DMG.
- **Check the install location**: Open the downloaded DMG instead of replacing the app when its current location is not writable.

### Validation

- All 91 tests passed, including 6 new tests. The v0.2.10 (build 28) DMG was generated and its signature and checksum verified.
- Verified the install script's replacement and relaunch, and restoration of the previous app after a copy failure, by running it.
- Verified download, SHA-256 checks, reuse of an identical file, rejection of a wrong checksum, cancellation, and DMG mount, copy, validation, and detach with the live v0.2.9 release DMG.
- The menu UI alerts and replacement and relaunch of an installed app require confirmation when updating to the next release.

v0.2.9 and earlier do not include this feature, so install this version manually from the DMG. macOS may ask for Desktop folder access on the first download, and may ask again after updates because the app is ad-hoc signed.
