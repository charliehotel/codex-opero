# codex-opero v0.2.8

## 한국어

Claude OAuth 자동 갱신을 개선하고, Antigravity 앱이 꺼져 있어도 Google 서버에서 쿼터를 직접 조회합니다.

### 변경 사항

- **Claude 자동 갱신**: 만료까지 60초 이하가 남았거나 사용량 조회가 `401`을 반환하면 저장된 갱신 토큰으로 갱신합니다. 갱신 후에도 인증이 거부되면 반복 요청을 중단하고 재로그인을 안내합니다.
- **Claude 인증정보 보존**: 원래 저장소에 갱신 결과를 반영하고 JSON의 다른 필드를 유지합니다. 키체인 항목은 재생성하지 않고 데이터만 갱신하여 기존 접근 제어와 `항상 허용` 권한을 보존합니다. 조회·갱신 중 원본 계정이나 인증정보가 바뀌면 다시 확인하여 이전 응답으로 덮어쓰지 않도록 합니다.
- **Claude 요청 제한 준수**: 조회·토큰 갱신의 `429` 응답에서 `Retry-After`를 따르며, 유효한 값이 없으면 대기 시간을 단계적으로 늘립니다. 수동 새로고침도 대기 시간을 준수합니다.
- **Antigravity 직접 조회·자동 갱신**: 기존 Antigravity 또는 `agy` 로그인으로 Google Cloud Code에서 계정 프로젝트와 쿼터를 조회합니다. 앱이나 `agy`를 백그라운드에서 실행하지 않으며, 토큰 만료 직전 또는 `401` 응답 시 Google OAuth로 자동 갱신합니다.
- **Antigravity 원본 인증 보존**: IDE 데이터베이스는 읽기 전용으로 열고 `agy` 인증은 수정하지 않습니다. 갱신된 토큰은 전용 `codex-opero.AntigravityOAuth` 키체인에 저장합니다. 원본 로그인 변경 시 이전 계정의 저장된 토큰을 재사용하지 않으며, 요청 중 계정 변경을 감지하면 이전 계정의 갱신 결과와 쿼터를 적용하지 않습니다.
- **Antigravity 호환성 유지**: 현재·이전 IDE 인증 형식, 기존 IDE 로컬 서비스 조회 경로와 주간(7d) 쿼터만 있는 계정을 지원합니다. Google 직접 조회의 `429` 대기 시간은 수동 새로고침에도 적용됩니다.

Google OAuth 클라이언트 설정은 설치된 공식 Antigravity/agy 바이너리에서 읽으며 소스나 배포 파일에 포함하지 않습니다. 갱신 시 공식 설치본이 필요합니다.

### 검증

- 전체 85개 테스트 재검증과 v0.2.8(build 26) DMG 생성, 서명·체크섬 검증을 완료했습니다.
- 실제 Antigravity 앱 종료 상태에서 자동 토큰 갱신·쿼터 조회에 성공했고, Claude 실제 사용량 조회도 성공했습니다.
- Claude 토큰의 실제 만료 후 서버 갱신과 메뉴 UI 동작은 미검증입니다.

자동 갱신에는 유효한 갱신 토큰이 필요하며, 서버의 토큰 철회나 로그인 무효화로 재로그인이 필요할 수 있습니다. 키체인의 `항상 허용`은 OAuth 유효기간을 늘리지 않으며, 앱 재빌드나 접근 정책 변경 시 재승인이 필요할 수 있습니다.

## English

Improve Claude OAuth refresh and fetch Antigravity quota directly from Google while the Antigravity app is closed.

### Changes

- **Automatic Claude refresh**: Refresh with the stored refresh token within 60 seconds of expiry or after a usage request returns `401`. Stop repeated attempts and request sign-in if authentication still fails after refresh.
- **Preserve Claude credentials**: Write back to the original store and retain unrelated JSON fields. Update only the existing Keychain item's data, preserving access controls and `Always Allow` grants without recreating the item. Recheck account or credential changes during requests to avoid overwriting them with an older response.
- **Respect Claude rate limits**: Honor `Retry-After` on usage and token refresh `429` responses, with increasing backoff when no valid value is provided. Manual refreshes respect the same cooldown.
- **Direct Antigravity fetching and refresh**: Reuse an existing Antigravity or `agy` login to resolve the account project and fetch quota through Google Cloud Code. Background refresh does not launch either app. Refresh access tokens through Google OAuth near expiry or after `401`.
- **Preserve Antigravity source credentials**: Open the IDE database read-only and leave `agy` credentials unchanged. Store refreshed tokens in the dedicated `codex-opero.AntigravityOAuth` Keychain item. Do not reuse cached tokens after the source login changes; reject the previous account's refresh results and quota when an account change is detected during a request.
- **Keep Antigravity compatibility**: Support current and legacy IDE credential formats, the existing IDE local-service fallback, and weekly-only (7d) accounts. Manual refreshes also respect `429` cooldowns on the direct Google path.

Google OAuth client configuration is read from the installed official Antigravity/agy binary rather than embedded in source or release artifacts. An official installation is required for token refresh.

### Validation

- All 85 tests passed on revalidation. The v0.2.8 (build 26) DMG was generated and its signature and checksum verified.
- Live automatic token refresh and quota retrieval succeeded with Antigravity closed. Live Claude usage retrieval also succeeded.
- Claude refresh through the live server after actual token expiry and menu UI behavior remain unverified.

Automatic refresh requires a valid refresh token; server-side revocation or invalidated sessions can still require sign-in. Keychain `Always Allow` does not extend OAuth token lifetimes. App rebuilds or access-policy changes may require authorization again.
