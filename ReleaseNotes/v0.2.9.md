# codex-opero v0.2.9

## 한국어

Claude Code에서 `security`의 `Claude Code-credentials` 키체인 접근 요청이 `항상 허용`을 눌러도 반복해서 표시되던 문제를 수정합니다.

### 변경 사항

- **Claude 키체인 접근 방식 변경**: Claude 인증정보를 Claude Code와 같은 `/usr/bin/security`로 읽고 갱신합니다. 앱이 키체인 API로 항목에 직접 접근하지 않으므로, 앱을 재빌드해도 항목의 접근 제어 목록과 파티션 목록에 새 서명이 추가되거나 목록이 다시 작성되지 않습니다.
- **Claude 인증정보 갱신 보호 유지**: 갱신 직전 계정과 저장된 데이터를 다시 확인하여 Claude Code가 먼저 변경한 인증정보를 덮어쓰지 않습니다. 저장 후 다시 읽어 결과를 확인합니다. Claude Code와 같이 작은 데이터는 `security -i` 표준 입력으로, 큰 데이터는 명령 인자로 전달합니다.
- **패키징 검증 추가**: 실행 파일의 빌드 SDK가 설치된 Xcode SDK와 일치하지 않으면 패키징을 중단합니다.

Antigravity 전용 키체인 항목은 기존 방식을 유지합니다.

### 검증

- 전체 85개 테스트가 통과했으며 v0.2.9(build 27) DMG 생성, 서명·체크섬 검증을 완료했습니다.
- 실제 `Claude Code-credentials` 항목 읽기와 항목이 없는 경우의 처리를 확인했습니다. 임시 키체인 항목으로 갱신, 이전 데이터 기준의 갱신 거부, 큰 데이터 갱신을 검증했습니다.
- 실제 Claude 토큰 만료 후의 키체인 갱신과 반복 승인 요청이 사라지는지는 장기 사용으로 확인이 필요합니다.

이전 버전이 키체인 항목에 추가한 `codex-opero` 접근 권한은 자동으로 제거되지 않습니다. 필요하면 키체인 접근 앱의 `Claude Code-credentials` 접근 제어 탭에서 삭제할 수 있습니다. 큰 인증정보를 갱신하는 동안에는 Claude Code와 마찬가지로 토큰이 잠시 프로세스 인자에 표시됩니다.

## English

Fix Claude Code repeatedly showing the `security` Keychain access prompt for `Claude Code-credentials`, even after choosing `Always Allow`.

### Changes

- **Change Claude Keychain access**: Read and update Claude credentials through `/usr/bin/security`, the same tool Claude Code uses. The app no longer accesses the item through the Keychain API, so rebuilding the app no longer adds new signatures to the item's access control and partition lists or rewrites them.
- **Keep Claude credential update protection**: Recheck the account and stored data immediately before updating to avoid overwriting credentials Claude Code changed first. Read back after writing to confirm the result. As in Claude Code, pass small payloads through `security -i` standard input and large payloads as command arguments.
- **Add packaging verification**: Abort packaging when the executable's build SDK does not match the installed Xcode SDK.

The dedicated Antigravity Keychain item keeps its existing access method.

### Validation

- All 85 tests passed. The v0.2.9 (build 27) DMG was generated and its signature and checksum verified.
- Verified reading the live `Claude Code-credentials` item and handling of a missing item. Verified updates, rejection of updates against stale data, and large-payload updates with a temporary Keychain item.
- Keychain updates after actual Claude token expiry, and whether the repeated prompts stop, require longer real-world use to confirm.

`codex-opero` access entries added to the Keychain item by earlier versions are not removed automatically. They can be deleted from the Access Control tab of `Claude Code-credentials` in Keychain Access if needed. While large credentials are being updated, the token briefly appears in process arguments, as it does with Claude Code.
