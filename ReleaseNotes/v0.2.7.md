# codex-opero v0.2.7

## 한국어

이번 릴리즈는 Antigravity 2.26.0에서 로그인하고 앱을 실행해 두어도 사용량이 `--/--`로 표시되던 문제를 수정합니다.

### 변경 사항

- **Antigravity 사용량 조회 복구**: 최신 Antigravity가 로컬 서버의 인증 토큰을 로그에 남기지 않으면서 연결 정보를 찾지 못하던 문제를 수정했습니다. 실행 중인 Antigravity 서버의 인자에서 토큰을 읽어 사용량을 조회합니다.
- **기존 버전 호환 유지**: 이전 버전의 로그 기반 연결 방식과 주간(7d) 쿼터만 반환되는 계정의 표시를 유지합니다.

### 검증

- 전체 50개 테스트가 통과했습니다. 로그에 토큰이 없는 최신 버전과 이전 버전의 연결 방식, 주간 쿼터만 있는 응답을 검증했습니다.
- macOS의 Antigravity 2.26.0에서 실제 조회와 메뉴의 사용량 표시를 확인했습니다.

Antigravity 사용량을 조회하려면 Antigravity 앱이 실행 중이어야 합니다.

## English

This release fixes Antigravity usage appearing as `--/--` even when signed in with Antigravity 2.26.0 running.

### Changes

- **Restore Antigravity quota fetching**: Recent Antigravity versions no longer log the local server's authentication token. Read the token from the running Antigravity server's arguments to restore quota requests.
- **Preserve compatibility**: Keep the log-based connection fallback for older versions and support accounts that return only weekly (7d) quota.

### Validation

- All 50 tests passed, covering current and legacy connection discovery and weekly-only quota responses.
- Verified live quota retrieval and the menu display with Antigravity 2.26.0 on macOS.

Antigravity must remain running for quota fetching.
